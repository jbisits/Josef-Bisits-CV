\section{Model development}
In 2026, I added diagnostics to the source code for the Modular Ocean Model version 6 (MOM6) to compute local spurious mixing due to the advection scheme and vertical remapping.
The code that I added was reviewed by developers from ACCESS-NRI. \\
\vspace{0.5em}
During my PhD, I wrote a diagnostic to compute seawater density during a simulation for a fluid dynamics software package called \texttt{Oceananigans.jl}.
This package has been used in 87 peer reviewed journal articles to date, and the diagnostic I added is used in the main paper "High-level, high-resolution ocean modelling at all scales with Oceananigans" that details the software package.
This diagnostic, and other bug fixes I have made, were all reviewed by the lead Oceananigans team. \\
\vspace{0.5em}
I have used \texttt{Oceananigans.jl} to build high resolution Direct Numerical Simulation models of fluid flow and for the work that I did for Submarine as an ocean modelling contractor where I built a Large Eddy Simulation of Port Angeles Harbour (in Washington United States) with observed bathymetry, and ROMS output as forcing.
